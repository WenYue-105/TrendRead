# 市场监管新闻监测配置

本项目用于定时监测市场监管相关热点与官方公开信息，并通过 PushPlus 推送至微信。

## 检索平台

### 热点平台

- 今日头条
- 百度热搜
- 华尔街见闻
- 澎湃新闻
- Bilibili 热搜
- 财联社热门
- 凤凰网
- 贴吧
- 微博
- 抖音
- 知乎

热点平台抓取的是当前热门榜单标题，不执行平台内全站搜索。

### 官方平台

- 国家市场监督管理总局：新闻动态、通知通告
- 北京市市场监督管理局：市场监管动态、通知、公示公告

官方平台抓取对应栏目页的最新文章标题与链接。

## 检索范围与关键词

项目按新闻标题进行关键词匹配；标题命中后才会进入报告和推送内容。当前关键词如下：

```text
市场监管
市场监督管理
国家市场监督管理总局
市场监管局
反垄断
反不正当竞争
价格监管
价格违法
食品安全
食品抽检
产品质量
产品召回
缺陷产品
消费维权
消费者权益
行政处罚
信用监管
经营异常
严重违法失信
```

关键词仅匹配标题，不读取新闻正文。因此，标题未包含关键词但正文相关的内容不会被命中。

## 推送时间与方式

- 推送渠道：PushPlus 微信推送。
- 运行时间：每天北京时间 09:00 至 21:00，每个整点一次。
- GitHub Actions 在云端执行，不需要用户保持登录 GitHub。
- GitHub Actions 的定时任务在高峰期可能出现数分钟延迟，不属于严格实时调度。

`crawler.yml` 的定时配置：

```yaml
- cron: '0 1-13 * * *'
```

该表达式使用 UTC，等同于北京时间 09:00 至 21:00 的每小时整点。

## 永久去重规则

- 首次运行只建立历史标题基线，不发送推送。
- 后续运行仅推送此前从未出现过的“来源 + 标题”。
- 去重记录保存在 `output/seen_titles.json`，跨天、跨周、跨月持续有效。
- 请勿删除 `output/seen_titles.json`；删除后会重新建立基线。
- 完全相同的标题若来自不同来源，会分别计为一条；同一事件若标题发生改写，仍可能被视为新标题。

## 配置项

PushPlus Token 应在 GitHub 仓库中配置为 Actions Secret：

```text
名称：PUSHPLUS_TOKEN
值：你的 PushPlus Token
```

不要将 Token 写入 `main.py`、`crawler.yml` 或其他公开文件。

## 运行与维护

- 可在 GitHub 仓库的 `Actions → Hot News Crawler` 查看运行状态和日志。
- 某个平台或官方栏目抓取失败时，可在 `crawl` 日志中查看失败来源。
- 每次运行会将报告与去重记录写入 `output` 并提交回仓库；长期使用后该目录会持续增长。
- 公开仓库的定时工作流若长期没有仓库活动，可能被 GitHub 自动停用；应定期确认工作流仍为启用状态。
